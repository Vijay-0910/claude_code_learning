Step 5 · Biggest free win

Prompt caching

Same periya prefix (system prompt, document, tools) thirumba thirumba anuppum podhu, adhai cache pannina reads romba cheap (Opus 5.5: cache read $0.20/MTok vs input $4).

Golden rule: prefix match. Render order tools → system → messages. Prefix-la oru byte maarinaalum adhukku apram irukkura cache ellam invalid.

cache.ts
// Simplest: top-level auto caching (last cacheable block)
const r1 = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  cache_control: { type: "ephemeral" },
  system: bigPolicyDocument,                // periya, maaraadha content
  messages: [{ role: "user", content: "Refund policy enna?" }],
});

// Manual breakpoint, 1 hour TTL
const r2 = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  system: [{ type: "text", text: bigPolicyDocument,
             cache_control: { type: "ephemeral", ttl: "1h" } }],   // default TTL 5 min
  messages: [{ role: "user", content: "Shipping policy enna?" }],
});

console.log(r2.usage.cache_creation_input_tokens);  // cache-la write (~1.25x cost, 5-min TTL)
console.log(r2.usage.cache_read_input_tokens);      // cache-la irundhu read (cheap)
console.log(r2.usage.input_tokens);                 // uncached (full price)
Silent cache killer
system: `Today is ${new Date()}.
${bigPolicyDocument}`

Ovvoru request-um prefix vera. cache_read_input_tokens eppovum 0.

Right
system: bigPolicyDocument,   // frozen
messages: [{ role: "user",
  content: `Today: ${date}. ${question}` }]

Dynamic content kadaisila, last breakpoint-ku apram.

Step 6 · 50% off

Message Batches API

Udane answer vendaam (nightly reports, bulk classification) na batch: 50% cheaper.

batch.ts
const batch = await client.messages.batches.create({
  requests: tickets.map((t) => ({
    custom_id: t.id,                       // result-ah match panna idhu dhaan key
    params: {
      model: "claude-haiku-5-5",
      max_tokens: 256,
      messages: [{ role: "user", content: `Classify: ${t.text}` }],
    },
  })),
});

// Poll until ended
let status = await client.messages.batches.retrieve(batch.id);
while (status.processing_status !== "ended") {
  await new Promise((r) => setTimeout(r, 60_000));
  status = await client.messages.batches.retrieve(batch.id);
}

for await (const result of await client.messages.batches.results(batch.id)) {
  if (result.result.type === "succeeded") {
    console.log(result.custom_id, result.result.message.content);
  } else {
    console.log(result.custom_id, result.result.type);   // errored | canceled | expired
  }
}
FactValue
SizeUp to 100,000 requests or 256 MB per batch
TimeMost within 1 hour; max 24 hours
Results29 days available; any order-la varum, custom_id vachu match, position vachu illa
FeaturesVision, tools, caching ellam work. Fast mode + server-side fallbacks batch-la illa

Step 12 · Check

Quick quiz (exam style)

1. Chatbot-la 20K-token policy doc ovvoru request-layum anuppureenga. Cost kammi panna first step?

Prompt caching: doc-ah frozen system block-la vechu cache_control. Reads romba cheap.

2. Caching on panniyum cache_read_input_tokens eppovum 0. Possible causes?

Prefix-la dynamic content (timestamp, UUID), tools / model maarudhu, unsorted JSON, prefix minimum-ku kammi, illa vera workspace.

3. Opus 5.5-la budget_tokens: 8000 anuppunaa?

400 error. thinking: {type: "adaptive"} + output_config.effort use pannunga.

4. 50,000 product descriptions overnight summarize pannanum. Best approach?

Batch API (50% cheaper, 24h-kulla), cheap model (Haiku) + eval vachu quality check, results-ah custom_id vachu map.

5. Prompt tokens estimate panna tiktoken use pannalaamaa?

Illa. Adhu OpenAI tokenizer, Claude-ku undercount. messages.countTokens use pannunga.

6. Company full-aa AWS-la. Claude eppadi access?

Amazon Bedrock: AnthropicBedrockMantle client, model ID anthropic. prefix-oda. Feature availability platform-wise check pannunga.

Interview line

"Naan cost-ah per completed task-aa measure pannuven. Mudhalla free wins: prompt caching (frozen prefix, cache_read verify), input hygiene, batch. Apram eval vachu effort tune, kadaisila dhaan cheaper model. Thinking-ku adaptive + effort; budget_tokens pudhu models-la removed."
