Step 0 · Full picture first

Ellaam eppadi connect aagudhu?

Neenga→ App (Claude Code / unga code)→ API→ Model (Claude)⇄ Tools (files, web, DB)

Oru line-la: Neenga prompt anuppureenga. Adhu tokens-aa udaiyum. Model adhai padichu adutha tokens predict panni answer ezhudhum. Model-ku tools kudutha, adhu "indha file-ah padi" nu kekkum; unga app adhai run panni result thirumba anuppum. Indha loop thaane odinaa adhu agent.

Step 2 · Token

Token na enna?

Model words-ah padikkaadhu. Text-ah chinna chinna pieces-aa udaichu padikkum. Andha oru piece = oru token.

MeaningText-oda chinna unit. Sila neram full word, sila neram word-oda paadhi, space, punctuation.
Daily lifeAuto meter kilometer-ku charge pannura maadhiri, AI token-ku charge pannum. Neraiya tokens = neraiya cost.
Rough ruleEnglish-la sumaar 3–4 characters = 1 token. Tamil, code, rare words-ku adhigam tokens aagum.
Input tokensNeenga anuppura text (prompt, files, history)
Output tokensModel ezhudhura answer. Idhu input-ah vida 5 madangu costly (Opus 5.5: input $4, output $20 per 1M tokens)

Step 5 · Inside

Model eppadi answer ezhudhudhu?

  1. Unga text → tokens-aa udaiyum
  2. Model ellaa tokens-aiyum paathu, adutha oru token edhuvaa irukkalaam nu probability calculate pannum
  3. Oru token select pannum, adhai end-la serkkum
  4. Thirumba step 2. Answer mudiyura varaikkum (stop) repeat. Adhanaala dhaan answer word-by-word stream aagudhu
Non-deterministicSame question rendu thadava kettaa konjam vera answer varalaam. Normal dhaan.
Thinking / reasoningAnswer ezhudhurathukku munnadi model ulla yosikkum. Kashtamaana problem-ku better result, aana adhigam tokens + time.
EffortEvvalavu yosikkanum nu neenga set pannalaam: low … max. Simple task = low (cheap, fast).
max_tokensAnswer evvalavu neelam max varalaam nu limit. Limit-la nikkiradhu = answer paadhi-la cut aagum.

Step 10 · Agent

Agent na enna?

Agent = Model + Tools + Loop. Goal kudutha, mudiyura varaikkum thaane steps edukkum.

Chatbot
Neenga: "Bug fix pannu"
Bot: "Indha code try pannunga..."
(Neenga copy, paste, run, error,
thirumba kekkuradhu...)

Oru question → oru answer. Neenga dhaan ellaa velaiyum.

Agent
Neenga: "Bug fix pannu, tests pass aaganum"
Agent: file padikkum → bug kandupidikkum
→ edit pannum → npm test run pannum
→ fail → thirumba fix → pass ✅ → "Mudinjuchu"

Goal → loop: yosi, tool use pannu, result paaru, repeat.

Goal→ Think→ Use tool→ See result→ Done? illana thirumba Think

Step 12 · Check

Quick quiz

Mudhalla neengalae sollunga, apram click.

1. Model-kulla database irukkaa? Yen sila neram thappu sollum?

Illa. Model patterns vachu adutha token predict pannum. Adhanaala illaadhadhai confident-aa sollalaam (hallucination). Fix: tests, docs, verify.

2. Token na enna? Yen namakku mukkiyam?

Text-oda chinna piece. Cost, speed, context limit ellaam tokens-la dhaan count aagum. Output tokens input-ah vida costly.

3. Claude "pazhaiya message nyaabagam vachukkudhu". Unmaiyaa?

Model-ku memory illa. App ovvoru request-laiyum full history-ah context window-la thirumba anuppudhu.

4. Chatbot vs Agent difference?

Chatbot: oru question → oru answer. Agent: model + tools + loop. Goal mudiyura varaikkum thaane think → tool → result → repeat.

5. 10,000 emails-ah "spam / not spam" nu classify pannanum. Endha model?

Haiku (cheap, fast, simple task). Urgent illana Batch API vachu innum 50% save.

Interview line

"An LLM predicts the next token. Context window is its working memory, and it has no memory between requests. Give it tools and run it in a loop, and that's an agent. Claude Code is a coding agent like that."
