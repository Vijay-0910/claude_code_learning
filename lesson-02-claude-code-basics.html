Step 0 · Why

Claude Code na enna? ChatGPT-la code kekkuradhukkum idhukkum enna difference?

Chat (copy-paste)
Neenga code copy panni chat-la podureenga
AI answer tharudhu
Neenga copy panni file-la paste
Run panni error vandha thirumba copy...

AI-ku unga project theriyaadhu. Neenga dhaan "hands".

Agent (Claude Code)
Claude unga files-ah padikkum
Plan pannum → files edit pannum
Tests run pannum → fail aana fix pannum
Neenga review + approve pannureenga

AI-ku tools irukku: Read, Edit, Bash. Neenga dhaan "reviewer".

Agentic loop: Gather context → Take action → Verify result → repeat. Idhu dhaan Claude Code, Codex, Cursor agent, Gemini CLI ellathukkum common core.

Step 1 · Start

Session start pannuradhu

Eppovum project folder-kulla poyi dhaan start pannanum. Claude andha folder-ah dhaan "project" nu edukkum.

CommandEnna pannum
claudeInteractive session start
claude "explain this project"First prompt-oda start
claude -cContinue: indha folder-la kadaisi conversation-ah thodarum
claude -rResume: pazhaiya sessions list-la irundhu select pannalaam
claude -n "todo-feature"Session-ku name kudukkum (resume panna easy)
claude -p "query"Print mode: answer print panni exit. Scripts/CI-ku (Level 4)
claude --versionVersion check
claude doctorInstall/health check. Edhavadhu work aagalana mudhalla idhu
claude updateLatest version-ku update
Wrong
cd ~
claude

Home folder-la start. Claude-ku endha project nu theriyaadhu, unga ella files-um scope-la varum.

Right
cd ~/Desktop/Learn_Claude_Code/todo-api
git status
claude

Project folder + git ready. Thappu aana thirumba poga mudiyum.

Step 3 · Safety

Permission modes: Shift+Tab

Claude ovvoru action-kkum unga permission kekkanumaa illaiyaa nu decide pannuradhu. Shift+Tab adikka adikka mode maarum; screen keezha current mode theriyum.

ModeEnna nadakkumEppo use pannanum
defaultOvvoru edit / command-kkum permission kekkumPuthu project, kathukkura time. Ippo neenga idhula irunga
acceptEditsFile edits auto-accept; commands-ku innum kekkumPlan approve pannittinga, edits trust pannureenga
planRead mattum. Edhuvum maathaadhu, plan mattum tharumPuthu feature / periya change-ku munnadi. Best habit
autoSafety classifier safe actions-ah auto approve pannum, risky-ah blockExperienced aanappuram, trusted project-la
bypassPermissionsEdhuvum kekkaadhu (--dangerously-skip-permissions)Internet illaadha sandbox/container mattum. Real machine-la vendaam
Permission prompt vandha options: Yes (indha thadava), Yes, don't ask again (indha type-ku always), No + enna vera maadhiri pannanum nu sollunga. "No" sollitu reason sonna Claude adhukku yetha maadhiri maathikkum.

Step 7 · Prompting

Nalla prompt: Goal + Location + Constraints + Done

Wrong
todo app pannu

Endha language? Endha framework? Test venumaa? Claude guess pannum, neenga ethirpaakkaadha result varum.

Right
Goal: GET /todos endpoint, in-memory array return pannanum.
Location: src/app.js, tests/todos.test.js
Constraints: Express + vitest mattum. Database vendaam.
Done: npm test pass aaganum.

Claude-ku eppo "mudinjuchu" nu theriyum, adhuve verify-um pannum.

Step 9 · Check

Quick quiz

Mudhalla neengalae yosichu sollunga, apram click.

1. Puthu feature start pannum podhu endha mode best? Yen?

Plan mode. Claude read mattum pannum, plan tharum. Neenga approve pannra varaikkum edhuvum maaradhu. Thappaana direction-ah code ezhudhurathukku munnadiye pidikkalaam.

2. Oru task mudinjudhu, adutha unrelated task start pannanum. Enna pannuveenga?

/clear. Pazhaiya context puthu task-ah kuzhappum, tokens-um waste. Long-ah ore task-na /compact.

3. Claude thappaana file-ah edit panna start pannudhu. Udane enna?

Esc adichu stop. Already maathiyirundha Esc Esc / /rewind, illana git restore .

4. @file and !command difference?

@ = file-ah context-la serkkum (Claude padikka). ! = neengalae shell command run pannureenga, output Claude-kkum theriyum.

Interview line

"Claude Code oru agentic coding tool: context gather pannum, edit pannum, tests run panni verify pannum. Naan plan mode-la start panni plan review pannuven, default permissions-la ovvoru change-um paappen, tests pass aanappuram dhaan commit pannuven."
