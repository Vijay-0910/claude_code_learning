Step 0 · Why

Terminal-ah thaandi Claude Code

Basics + advanced mudinjaachu. Ippo real team workflow: PR-la @claude, IDE-kulla diff, laptop close pannaalum odura background/cloud sessions, parallel worktrees. Interview-la "naan Claude Code-ah team-la eppadi use panren" nu kekkum podhu idhu dhaan answer.

Wrong

Claude odum podhu wait pannuradhu

Neenga dhaan bottleneck.

Right

claude agents  → rendaiyum monitor

Parallel, isolated, neenga review mattum.

Step 1 · CI

GitHub Actions: PR-la @claude

Action: anthropics/claude-code-action@v1. Agent SDK mela build pannadhu.

SetupEnna pannum
/install-github-appQuick setup: GitHub App install, secret add, workflow PR ready pannum. github.com repos mattum; gh auth login munnadi venum; repo admin access venum
ANTHROPIC_API_KEYRepo secret: API key (Claude Console)
CLAUDE_CODE_OAUTH_TOKENSubscription token: claude setup-token vachu generate
Interactive modeprompt input illana: comment-la @claude mention pannaa odum
Automation modeprompt input irundha: event / cron-la thaane odum
.github/workflows/claude.yml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      id-token: write
      actions: read
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          claude_args: "--max-turns 5"
InputMeaning
promptInstructions or skill (/skill-name)
claude_argsCLI flags: --max-turns, --model, --allowedTools, --mcp-config
trigger_phraseDefault @claude
settingsClaude Code settings JSON / path
plugins, plugin_marketplacesPlugins install panni use
use_bedrock / use_vertex / use_foundryCloud provider vazhiya, OIDC auth
Wrong
anthropic_api_key: "sk-ant-abc123..."

Key repo-la commit. Leak.

Right
anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}

GitHub Secret. Plus --max-turns + workflow timeout = cost control.

Security built-in: triggering user-ku repo write access venum; bot actors default-aa reject (loop thadukka). GitLab-ku thani page irukku (GitLab CI/CD).
