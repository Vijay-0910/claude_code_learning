Step 0 · Why

Workflow vs Agent: enna difference?

Workflow
Unga CODE path decide pannum:
step 1 → LLM call → step 2 → LLM call
Predictable, cheap, test panna easy

Steps munnadiye theriyum na idhu.

Agent
MODEL path decide pannum:
while (model wants a tool) {
  run tool → result model-ku
}

Flexible, aana costly, slow, unpredictable. Steps theriyaadha open-ended tasks-ku mattum.

Golden rule: start simple. Single call → workflow → agent. Adutha level-ku move panna proof venum (simple version fail aagudhu nu).

Step 4 · Option 2

Tool Runner: SDK loop pannum

runner.ts
import Anthropic from "@anthropic-ai/sdk";
import { betaZodTool } from "@anthropic-ai/sdk/helpers/beta/zod";
import { z } from "zod";

const client = new Anthropic();

const getWeather = betaZodTool({
  name: "get_weather",
  description: "Get current weather for a location",
  inputSchema: z.object({
    location: z.string().describe("City and state, e.g., San Francisco, CA"),
  }),
  run: async (input) => `72°F and sunny in ${input.location}`,
});

// tool_use → run() → tool_result → repeat, until Claude finishes
const finalMessage = await client.beta.messages.toolRunner({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  tools: [getWeather],
  messages: [{ role: "user", content: "What's the weather in Paris?" }],
});

console.log(finalMessage.content);
Manual loop (option 1) concept: response stop_reason === "tool_use" aana, ella tool_use blocks-um run panni, ella tool_result-um oru user message-la thirumba anuppunga; fail aana is_error: true. Full code Lesson 7 (Tool use)-la.

agent.ts
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Review utils.py for bugs that would cause crashes. Fix any issues you find.",
  options: {
    allowedTools: ["Read", "Edit", "Glob"],   // least privilege
    permissionMode: "acceptEdits"
  }
})) {
  if (message.type === "assistant" && message.message?.content) {
    for (const block of message.message.content) {
      if ("text" in block) console.log(block.text);
      else if ("name" in block) console.log(`Tool: ${block.name}`);
    }
  } else if (message.type === "result") {
    console.log(`Done: ${message.subtype}`);
  }
}
agent.py (Python equivalent)
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage

async def main():
    async for message in query(
        prompt="Review utils.py for bugs that would cause crashes. Fix any issues you find.",
        options=ClaudeAgentOptions(allowed_tools=["Read", "Edit", "Glob"], permission_mode="acceptEdits"),
    ):
        if isinstance(message, ResultMessage):
            print(f"Done: {message.subtype}")

asyncio.run(main())

Step 11 · Check

Quick quiz (exam style)

1. Invoice-la irundhu 5 fields extract pannanum, daily 10,000 invoices. Agent venumaa?

Illa. Single call + structured output; latency matter illana Batch API (50% cost). Complexity check fail.

2. Customer message → billing / technical / sales team. Endha pattern?

Routing.

3. Marketing copy brand guidelines meet aagura varaikkum improve pannanum. Pattern?

Evaluator-optimizer (Managed Agents-la outcomes idhe idea).

4. Unga sondha Kubernetes-la, built-in file/bash tools-oda coding agent venum. Option?

Claude Agent SDK: Claude Code harness + built-in tools, neenga host.

5. Nightly report agent, unga servers illama, versioned config, API keys sandbox-la theriya koodaadhu. Option?

Managed Agents: deployment (cron) + vault credentials + versioned agent.

6. Agent production-la DROP TABLE run panna koodaadhu, 100% guarantee venum. System prompt-la sonna podhumaa?

Podhaadhu. PreToolUse hook (deterministic deny) + least-privilege tools / DB user.

Interview line

"Naan simplest tier-la start pannuven: single call, apram chaining / routing maadhiri workflow, open-ended-aa irundhaa dhaan agent. Custom tools-ku Tool Runner, built-in coding tools venumna Agent SDK, hosted long-running agents-ku Managed Agents. Heavy reading-ku subagents, must-never-happen actions-ku hooks."
