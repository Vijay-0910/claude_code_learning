Step 11 · Check

Quick quiz (exam style)

1. Company ellaam AWS-la. Message Batches + Managed Agents venum, AWS IAM billing-um venum. Bedrock-aa, Claude Platform on AWS-aa?

Claude Platform on AWS. Anthropic-operated, same-day API parity, AWS IAM + Marketplace billing. Bedrock-la Batches, Managed Agents illa.

2. claude.ai-la nalla answer vandhuchu, API-la same prompt weak answer. Yen?

claude.ai-la Anthropic system prompt, tools (search), memory, Project context irukku. API-la unga system + tools + history mattum. Context-ah explicit-aa anuppunga.

3. Team-ku ellaarukkum same Jira access Claude-la venum. Desktop local server-aa, remote connector-aa?

Remote MCP connector (HTTP): ellaa devices, web + desktop, central auth. Local stdio = oruthar machine-ku mattum.

4. Long Claude Code session-la quality kuraiyudhu, unrelated tasks mix aagudhu. Fix?

Session hygiene: task-ku task /clear, long task-ku /compact, stable info CLAUDE.md-la, unused MCP/plugins off.

5. Customer-facing chatbot build pannanum. claude.ai Project share pannalaamaa?

Illa. Product feature = Claude API + SDK (unga backend). claude.ai = individual / team productivity.

Interview line

"Knowledge work-ku claude.ai Projects, local tools-ku Desktop + MCP, coding-ku Claude Code, product features-ku Claude API, hosted agents-ku Managed Agents, cloud compliance-ku Claude Platform on AWS / Bedrock / Vertex / Foundry, feature availability check panni. API blank slate: system, tools, history ellaam naan dhaan anuppanum."
