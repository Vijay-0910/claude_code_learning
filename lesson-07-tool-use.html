Step 0 · Why

Model-ku internet, DB, unga code theriyaadhu. Tools dhaan bridge.

Myth
Claude en function-ah thaane run pannum

Illa. Claude "indha tool-ah indha input-oda call pannu" nu request mattum pannum. Execute pannuradhu unga code.

Reality
1. Neenga tools list anuppureenga
2. Claude: stop_reason "tool_use" + tool_use block
3. Unga code tool run pannum
4. tool_result thirumba anuppureenga
5. Claude final answer (or innoru tool call)

Idhu dhaan agentic loop. Claude Code-um ulla idhe dhaan.

Step 2 · Manual agentic loop

Loop-ah oru thadava kai-la ezhudhunga (exam + understanding)

src/agent.ts
import Anthropic from "@anthropic-ai/sdk";
import { tools } from "./tools.js";

const client = new Anthropic();

async function executeTool(name: string, input: unknown): Promise<string> {
  if (name === "get_weather") {
    const { location } = input as { location: string };
    return JSON.stringify({ location, temp_c: 31, condition: "humid" }); // fake data for practice
  }
  throw new Error(`Unknown tool: ${name}`);
}

const messages: Anthropic.MessageParam[] = [
  { role: "user", content: "Chennai-la ippo weather eppadi? Bangalore-um sollu." },
];

while (true) {
  const response = await client.messages.create({
    model: "claude-opus-5-5",
    max_tokens: 16000,
    tools,
    messages,
  });

  if (response.stop_reason === "end_turn") {
    for (const b of response.content) if (b.type === "text") console.log(b.text);
    break;
  }

  // server tool loop limit hit aana: assistant turn append panni re-send
  if (response.stop_reason === "pause_turn") {
    messages.push({ role: "assistant", content: response.content });
    continue;
  }

  const toolUses = response.content.filter(
    (b): b is Anthropic.ToolUseBlock => b.type === "tool_use",
  );
  if (toolUses.length === 0) break; // max_tokens, refusal, etc.

  // 1. Full assistant content append (tool_use blocks preserve aaganum)
  messages.push({ role: "assistant", content: response.content });

  // 2. ELLAA results-um ORE user message-la
  const results: Anthropic.ToolResultBlockParam[] = [];
  for (const t of toolUses) {
    try {
      results.push({ type: "tool_result", tool_use_id: t.id, content: await executeTool(t.name, t.input) });
    } catch (err) {
      results.push({ type: "tool_result", tool_use_id: t.id, is_error: true, content: String(err) });
    }
  }
  messages.push({ role: "user", content: results });
}
stop_reasonEnna pannanum
end_turnMudinjadhu. Text print
tool_useTools run panni tool_result anuppu
pause_turnServer tool loop (default 10 iterations) pause. Assistant content append panni re-send; "Continue" user message podaadheenga
max_tokensCut aayiduchu. Tool input truncated-aa irukkalaam: tool run pannaadheenga, max_tokens yetthi retry
refusalSafety decline. Andha turn-oda tools run pannaadheenga; stop_details paarunga
Loop-ku oru max iterations limit vachukkonga (e.g. 10). Illana bug irundhaa infinite loop + bill.
Step 3 · Parallel calls & errors

Wrong

  messages.push({ role: "user", content: [resultFor(t)] });

Step 5 · Tool Runner (beta)

Loop-ah SDK-ve pannum

Loop concept purinjappuram, real code-la Tool Runner default. Approval gates, error interception, streaming, compaction ellam idhulaiyum pannalaam.

src/runner.ts · npm i @anthropic-ai/sdk zod
import Anthropic from "@anthropic-ai/sdk";
import { betaZodTool } from "@anthropic-ai/sdk/helpers/beta/zod";
import { z } from "zod";

const client = new Anthropic();

const getWeather = betaZodTool({
  name: "get_weather",
  description: "Get current weather for a city. Call this when the user asks about weather.",
  inputSchema: z.object({
    location: z.string().describe("City and state, e.g. Chennai, TN"),
    unit: z.enum(["celsius", "fahrenheit"]).optional(),
  }),
  run: async (input) => `31°C and humid in ${input.location}`,
});

const finalMessage = await client.beta.messages.toolRunner({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  tools: [getWeather],
  messages: [{ role: "user", content: "Chennai weather?" }],
});

console.log(finalMessage.content);
Python equivalent
from anthropic import Anthropic, beta_tool

client = Anthropic()

@beta_tool
def get_weather(location: str, unit: str = "celsius") -> str:
    """Get current weather for a city.

    Args:
        location: City and state, e.g. Chennai, TN.
        unit: "celsius" or "fahrenheit".
    """
    return f"31°C and humid in {location}"

runner = client.beta.messages.tool_runner(
    model="claude-opus-5-5", max_tokens=16000,
    tools=[get_weather],
    messages=[{"role": "user", "content": "Chennai weather?"}],
)
print(runner.until_done())

Step 8 · Safety

Human-in-the-loop approval

Side effects irukkura tools (email anuppuradhu, refund, delete) Claude sonnaa udane run aaga koodaadhu.

gate inside the tool
const issueRefund = betaZodTool({
  name: "issue_refund",
  description: "Refund an order. Only call after confirming the order id with the user.",
  inputSchema: z.object({ order_id: z.string(), amount_inr: z.number() }),
  run: async ({ order_id, amount_inr }) => {
    if (amount_inr > 2000) return "Declined: refunds above ₹2000 need a human agent.";
    const ok = await askHuman(`Refund ₹${amount_inr} for ${order_id}?`); // unga UI / CLI prompt
    if (!ok) return "The user declined this refund.";
    return await payments.refund(order_id, amount_inr);
  },
});

Step 10 · Check

Quick quiz (exam style)

1. Claude oru response-la 3 tool_use blocks anuppuchu. Results eppadi anuppanum?

Moonaiyum (concurrent-aa) run panni, moonu tool_result blocks-aiyum ore user message-la, ovvonnum matching tool_use_id-oda.

2. Opus 5.5-la tool_choice: { type: "tool", name: "extract" } anuppureenga. Result?

400. auto + prompt-la tool name sollunga + strict: true; JSON extract mattum-na structured outputs.

3. Database timeout aachu. Tool result-ah skip pannalaamaa?

Illa. is_error: true + informative message-oda tool_result anuppunga; ovvoru tool_use-kkum result kandippa venum.

4. Web search use pannumbodhu stop_reason: "pause_turn". Enna pannanum?

Assistant response.content-ah messages-la append panni adhe request re-send. "Continue" user message serkka vendaam; server resume pannum.

5. Refund tool-ku safety: prompt-la "₹2000 mela refund pannaadhe" pottaa podhumaa?

Podhaadhu. Limit-ah code-la (run function) enforce pannunga + human approval. Prompt = suggestion, code = guarantee.

6. Tool Runner vs Claude Agent SDK difference?

Tool Runner = Anthropic SDK-oda beta helper, unga tools-ku loop. Agent SDK = Claude Code harness library, built-in Read/Edit/Bash tools + subagents + hooks. Rendum harness mattum; deploy neengalae.

Interview line

"Tool use-la Claude call-ah request mattum pannum, execute pannradhu en code. Clear descriptions-oda narrow tools, strict schemas, ellaa parallel results-um ore message-la, failures-ku is_error, pause_turn handle. Side-effect tools-ku code-la limits + human approval. Default-aa Tool Runner, full control venumna manual loop."
