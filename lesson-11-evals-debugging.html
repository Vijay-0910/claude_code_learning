Step 3 · Run

Minimal eval runner (TypeScript)

Unga app-oda real entry point-ah call pannunga. Eval-kulla Claude call-ah thirumba ezhudhinaa production-ah measure pannala.

evals/run.ts
import { readFileSync, appendFileSync } from "node:fs";
import { classifyTicket } from "../src/classify";   // unga real app function

type Case = { id: string; input: string; expected: "refund" | "bug" | "other" };
const cases: Case[] = JSON.parse(readFileSync("evals/cases.json", "utf8"));

let pass = 0;
for (const c of cases) {
  const t0 = Date.now();
  const { label, usage } = await classifyTicket(c.input);   // app returns usage too
  const ok = label === c.expected;                          // programmatic grader
  if (ok) pass++;
  appendFileSync("evals/results.jsonl", JSON.stringify({
    id: c.id, ok, label, expected: c.expected,
    latency_ms: Date.now() - t0,
    input_tokens: usage.input_tokens, output_tokens: usage.output_tokens,
  }) + "\n");
}
console.log(`${pass}/${cases.length} passed`);
Cost per task: usage-la irundhu tokens × price. Guess pannaadheenga, oru pilot run panni measure pannunga. Per-request cost illa, per completed task cost dhaan real (retries, extra turns serthu). Cost $0.00 or latency 0 vandha adhu runner bug, result illa.

Step 6 · Code

Typed exception chain + request ID

Wrong
catch (e) {
  if (String(e).includes("rate")) retry();
}

String matching: message maarina break. Retryable vs non-retryable kalandhudum.

Right
catch (e) {
  if (e instanceof Anthropic.RateLimitError) ...
}

SDK typed classes. Most specific first.

call-claude.ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({ maxRetries: 2 });  // default 2: 408, 409, 429, >=500, connection errors auto-retry

try {
  const msg = await client.messages.create({ model: "claude-opus-5-5", max_tokens: 16000, messages });
  console.log("request id:", msg._request_id);    // log it; support-ku report panna
} catch (err) {
  if (err instanceof Anthropic.NotFoundError) {
    // 404: model ID check; retry pannaadheenga
  } else if (err instanceof Anthropic.RateLimitError) {
    // 429: SDK already retried; queue / slow down
  } else if (err instanceof Anthropic.APIConnectionError) {
    // network; APIError-ku munnadi check (TS-la idhu APIError subclass)
  } else if (err instanceof Anthropic.APIError) {
    console.error(err.status, err.name, err.message);   // other non-2xx
  } else {
    throw err;
  }
}
Timeout default 10 min (TS-la milliseconds-la configure: timeout: 20_000). Periya max_tokens-ku streaming use pannunga. Timeouts-um retry aagum, so wall-clock = timeout × (retries+1) varaikkum pogalaam. logLevel: "debug" HTTP bodies log pannum: local debugging-ku mattum.

Step 10 · Check

Quick quiz (exam style)

1. JSON.parse random-aa fail aagudhu, specially long outputs-la. Most likely cause?

stop_reason: "max_tokens": output truncated. max_tokens increase / streaming, and structured outputs use pannunga.

2. 429 vs 400: edhai retry pannanum?

429 (and 500, 529, connection errors) retryable. 400/401/403/404/413 retry pannina same error dhaan; request-ah fix pannanum.

3. Email summaries-ku eval venum. Correct answer ondru illa. Endha grader?

LLM-judge rubric (pointwise) with concrete atomic criteria; or v1 vs v2 compare-na pairwise blind judge (A/B randomize). Human labels vachu judge-ah calibrate.

4. Coding agent-ah eval pannanum. Transcript padichu grade pannalaamaa?

Better: end state grade: disposable workspace-la run, tests pass aagudhaa, expected files irukkaa. Taste-ku mattum judge.

5. Prompt v2: 22/25, v1: 20/25 (1 run each). Ship pannalaamaa?

Innum sollamudiyaadhu. 25 cases × 1 rep noise floor ~±20 points. More cases / reps venum.

6. Support ticket-ku Anthropic-kitta enna kudukkanum?

Request ID (msg._request_id / request-id header), timestamp, error type. Prompt content illaama kooda request ID vachu trace pannalaam.

Interview line

"Prompt changes-ah eval vachu dhaan ship panren: real cases, cheapest valid grader (programmatic first, calibrated LLM judge for open-ended), cost per task-um measure. Debugging-la typed SDK errors, request IDs log, stop_reason eppovum check, failing request-ah replay panni integration bug-aa model behaviour-aa nu isolate pannuven."
