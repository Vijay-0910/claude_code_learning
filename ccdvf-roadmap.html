Step 2 · Read this first

Claude Code mattum padicha pass aaga mudiyaadhu

Wrong assumption
Claude Code skills, MCP, hooks
nalla theriyum = certified

Claude Code domain = 3.1% (1–2 questions). Hooks 1%.

Reality
Claude API + app design      ≈ 33%
Models, tokens, caching      ≈ 17%
Agents (Agent SDK, patterns) ≈ 15%
Prompt + context engineering ≈ 11%
Tools + MCP                  ≈ 11%

Python/TypeScript-la Claude API vachu apps build pannanum. Adhu dhaan core.

Nalla news: Claude Code-la neenga kathukkura concepts (context, subagents, MCP, hooks, tool use) API side-la adhe concepts. Claude Code = practice ground, API = exam.
