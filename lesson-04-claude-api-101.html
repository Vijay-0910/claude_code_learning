Step 0 · Why

Claude Code vs Claude API

CCDV-F exam-la 33% indha area. "Claude-ah unga product-kulla integrate pannuradhu" dhaan main skill.

SurfaceYaar use pannuvaangaExample

Step 2 · Hello Claude

First messages.create

hello.ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const response = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  system: "You are a friendly tutor. Answer in simple Tanglish.",
  messages: [{ role: "user", content: "REST API na enna?" }],
});

// content = blocks array. .type check panni dhaan .text edukkanum
for (const block of response.content) {
  if (block.type === "text") console.log(block.text);
}

Step 4 · Conversations

Multi-turn: API is stateless

Server unga pazhaiya messages-ah nyaabagam vechukkaadhu. Ovvoru request-layum full history anuppanum.

chat.ts
import Anthropic from "@anthropic-ai/sdk";
const client = new Anthropic();

const messages: Anthropic.MessageParam[] = [];   // SDK type; sondha interface vendaam

async function chat(userText: string) {
  messages.push({ role: "user", content: userText });
  const response = await client.messages.create({
    model: "claude-opus-5-5", max_tokens: 16000, messages,
  });
  messages.push({ role: "assistant", content: response.content });  // full content, text mattum illa
  return response.content.filter((b) => b.type === "text").map((b) => b.text).join("");
}

console.log(await chat("En peru Vijay."));
console.log(await chat("En peru enna?"));   // history anuppunadhaala "Vijay" nu sollum
History neelamaa aaga aaga input tokens (cost) koodum. Theervu: prompt caching, compaction, context editing (Lesson 5, 6).
Step 5 · Streaming

Streaming: word by word

Yen? (1) Chat UI-la user udane paappaar. (2) Periya max_tokens / long output-la HTTP timeout varaadhu.

stream.ts
const stream = client.messages.stream({
  model: "claude-opus-5-5",
  max_tokens: 64000,
  messages: [{ role: "user", content: "Express middleware explain pannu" }],
});

stream.on("text", (delta) => process.stdout.write(delta));   // text delta mattum

const final = await stream.finalMessage();      // full Message object
console.log("\nOutput tokens:", final.usage.output_tokens);
EventEppo
message_startStart-la oru thadava (metadata)
content_block_startPuthu block (text / thinking / tool_use) start
content_block_deltaOvvoru chunk: text_delta, thinking_delta, input_json_delta
content_block_stopBlock mudinjadhu
message_delta / message_stopstop_reason, usage; mudivu
Wrong
await new Promise((resolve) => {
  stream.on("end", resolve);  // sondha wrapper
});

Errors, abort ellam miss aagum. SDK already panniduchu.

Right
const final = await stream.finalMessage();

SDK helper. Completion, error, abort ellam handle pannum.

Images & PDFs

content string-aa illaama blocks array-aa anuppunga. Image/document block-ah text-ku munnadi podunga.

vision.ts
import fs from "fs";

const imageData = fs.readFileSync("./screenshot.png").toString("base64");
const pdfData = fs.readFileSync("./invoice.pdf").toString("base64");

const response = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  messages: [{
    role: "user",
    content: [
      { type: "image", source: { type: "base64", media_type: "image/png", data: imageData } },
      { type: "document", source: { type: "base64", media_type: "application/pdf", data: pdfData } },
      { type: "text", text: "Screenshot-la error enna? Invoice total evvalavu?" },
    ],
  }],
});
Source typeExampleNote
base64{type:"base64", media_type, data}Local file. Base64 string-la newlines irukka koodaadhu
url{type:"url", url:"https://..."}Public image URL

Step 7 · Reuse & trust

Files API & citations

FeatureEnnaKey facts
Files APIOru thadava upload, file_id vachu pala requests-la useIppo GA: client.files.*, beta header vendaam. 500 MB per file, org-ku 100 GB. Upload/list/delete free; messages-la use pannina input tokens bill. Bedrock / Vertex-la illa
CitationsAnswer-la endha line document-la irundhu vandhudhu nu proofOvvoru document block-layum citations: { enabled: true } (ellathukkum or edhukkum illa). Structured output (output_config.format) kooda serthaa 400
files.ts
import Anthropic, { toFile } from "@anthropic-ai/sdk";
import fs from "fs";
const client = new Anthropic();

const uploaded = await client.files.upload({
  file: await toFile(fs.createReadStream("report.pdf"), undefined, { type: "application/pdf" }),
});

const response = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  messages: [{
    role: "user",
    content: [
      { type: "document", source: { type: "file", file_id: uploaded.id },
        title: "Q4 Report", citations: { enabled: true } },
      { type: "text", text: "Revenue growth evvalavu? Source kaattu." },
    ],
  }],
});

for (const block of response.content) {
  if (block.type === "text") {
    console.log(block.text);
    for (const c of block.citations ?? []) console.log("  ↳", c.cited_text);
  }
}
Citation location types: page_location (PDF, 1-indexed pages), char_location (plain text), content_block_location (custom content). Exam angle: "hallucination kammi pannanum, source verify pannanum" = citations.
Step 8 · Production

Errors, retries, rate limits

HTTPTS classRetry?Usual cause
400BadRequestErrorNoWrong params, removed param (temperature, budget_tokens)
401AuthenticationErrorNoKey illa / thappu
403PermissionDeniedErrorNoOrg/workspace-ku permission illa
404NotFoundErrorNoModel ID typo
413(APIError)NoRequest too large
429RateLimitErrorYesRate limit; retry-after header respect pannunga
500 / 529InternalServerErrorYesServer issue / overloaded
networkAPIConnectionErrorYesConnection fail
errors.ts
const client = new Anthropic({
  maxRetries: 4,      // default 2: 408, 409, 429, 5xx, connection errors auto-retry
  timeout: 60_000,    // TypeScript-la MILLISECONDS (Python-la seconds!)
});

try {
  const res = await client.messages.create({ /* ... */ });
} catch (err) {
  if (err instanceof Anthropic.NotFoundError) {
    console.error("Model ID check pannunga");             // fix code, retry vendaam
  } else if (err instanceof Anthropic.RateLimitError) {
    console.error("Rate limited, backoff panni later");   // retryable
  } else if (err instanceof Anthropic.APIConnectionError) {
    console.error("Network issue");                         // APIError-ku MUNNADI check
  } else if (err instanceof Anthropic.APIError) {
    console.error(`API error ${err.status}: ${err.message}`);
  } else {
    throw err;
  }
}

// Per-request override:
await client.messages.create({ /* ... */ }, { timeout: 5_000 });
Wrong
catch (e) {
  if (e.message.includes("rate")) retry();
}

String matching. Message maarina break aagum; retryable vs non-retryable theriyaadhu.

Right
catch (e) {
  if (e instanceof Anthropic.RateLimitError) ...
}

Typed classes, most-specific first. TS-la APIConnectionError APIError-oda subclass, adhanaala adhai mudhalla check.

Timeout-um retry aagum: worst case wall-clock = timeout × (maxRetries + 1). Production-la idhai calculate pannunga.

Step 10 · Check

Quick quiz (exam style)

1. User 3rd message-la "en peru enna" kekkuraar, Claude-ku theriyala. Yen?

API stateless. Mundhaya user + assistant messages-ah ovvoru request-layum messages-la anuppanum.

2. Long report generate pannum podhu request timeout aagudhu. Best fix?

Streaming (messages.stream + finalMessage()). Large max_tokens non-streaming-la HTTP timeout risk.

3. stop_reason: "max_tokens" vandhudhu. Meaning + fix?

Output limit-la cut aachu, answer incomplete. max_tokens increase pannunga (streaming kooda).

4. 429 vs 400: edhai retry pannanum?

429 (rate limit) retryable, retry-after respect pannunga. 400 request-la thappu; retry pannaalum same error, code fix pannanum.

5. Same 200-page PDF-ah 50 questions-ku use pannanum. Efficient vazhi?

Files API-la oru thadava upload, file_id reference. Kooda prompt caching (Lesson 5) serthaa input cost-um kurayum.

6. Legal app-la answer-ku source proof venum. Endha feature?

Citations: document blocks-la citations: {enabled: true}. Response text blocks-la cited_text + page location varum.

Interview line

"Claude API stateless Messages endpoint. Naan official SDK use panni key-ah env-la vechuppen, stop_reason check pannuven, long outputs-ku streaming + finalMessage, errors-ku typed exception chain: 429/5xx retry, 4xx fix."
