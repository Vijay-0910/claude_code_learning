# Learn Claude Code

Tanglish (Tamil + English) course for learning Claude Code and the Claude API, from zero to CCDV-F (Claude Certified Developer – Foundations) level.

## Open it
Open `index.html` in a browser. The left menu (`nav.js`) links every lesson and section.

## Contents
| File | Topic |
|---|---|
| `lesson-00-ai-basics.html` | Start here: model, token, context window, tool, agent |
| `practice-lab.html` | 57 hands-on tasks, Setup to Capstone |
| `ai-coding-path.html` | AI coding master path (overview, interview Q&A, flashcards) |
| `lesson-01` … `lesson-03`, `lesson-13` | Claude Code: terminal, basics, advanced, extras |
| `ccdvf-roadmap.html` | CCDV-F exam domains and study order |
| `lesson-04` … `lesson-12` | Claude API (TypeScript): API 101, models & cost, prompts, tool use, MCP server, agents, security, evals, ecosystem |
| `lesson-14-capstone-mock-exam.html` | Capstone project + 30-question practice exam |
| `LEARNING_PLAN.md` | Checklist and progress notes |

Practice exam questions are written for this course, not taken from the real exam.
