.claude/settings.json · auto-format after edit
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command",
            "command": "${CLAUDE_PROJECT_DIR}/.claude/hooks/prettier.sh" }
        ]
      }
    ]
  }
}
.claude/hooks/prettier.sh
#!/usr/bin/env bash
# Hook stdin-la JSON varum: {"tool_name": "Edit", "tool_input": {"file_path": ...}}
FILE=$(jq -r '.tool_input.file_path // empty')
[ -n "$FILE" ] && npx --no-install prettier --write "$FILE" >/dev/null 2>&1
exit 0
Exit codeMeaning
0Success. stdout JSON-aa irundha parse pannum
2Block. stderr message Claude-ku pogum (PostToolUse block panna mudiyaadhu, already nadandhuduchu)
otherNon-blocking error, continue
PreToolUse-la JSON vachum decide pannalaam: {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"rm blocked"}}. Values: allow / deny / ask / defer. Hook type command mattum illa: http, prompt, agent, mcp_tool-um irukku.

Step 11 · Check

Quick quiz (exam style)

1. "Commit pannurathukku munnadi eppovum tests odanum" nu guarantee venum. CLAUDE.md, Skill, Hook: edhu?

Hook. CLAUDE.md, Skill rendum Claude-oda decision; marandhudalaam. Hook = deterministic code, ovvoru thadavaiyum odum.

2. 200-file codebase-la oru function enga use aagudhu nu search pannanum, main context full aaga koodaadhu. Enna use pannuveenga?

Subagent (e.g. Explore). Thani context-la search pannum, summary mattum thirumba varum.

3. Team-la ellarukkum same Postgres MCP server venum, aana password share aaga koodaadhu. Eppadi?

claude mcp add -s project ... → .mcp.json commit, password ${DB_PASSWORD} env var-aa. Ovvoruthar machine-la avanga env var.

4. 30 skills install pannirukkom. Context window full aagidumaa?

Illa. Progressive disclosure: name + description mattum always loaded; full SKILL.md invoke pannum podhu dhaan.

5. PreToolUse hook exit code 2 return pannudhu. Enna nadakkum?

Tool call block aagum, stderr message Claude-ku feedback-aa pogum; Claude vera vazhi try pannum.

6. .claude/settings.json-la allow, ~/.claude/settings.json-la deny. Same rule. Edhu jeyikkum?

Deny. Deny rules eppovum allow-ah vida priority. (Precedence order project > user, aana deny always wins.)
