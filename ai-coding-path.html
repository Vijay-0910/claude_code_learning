Level 0 · Foundation

Terminal + Git

Why mudhalla idhu? AI agent orey nerathula 5–10 files-ah maathum. Git illana "enna maaruchu?", "pazhaya version-ku eppadi poradhu?" rendukkum answer illa. Git theriyaama AI tools use pannuradhu brake illama car oattura maadhiri.

Terminal basics

pwd                 # ippo endha folder-la irukken
ls -la              # folder-la enna irukku
cd ~/Desktop/Learn_Claude_Code   # folder maaruradhu
mkdir todo-api      # puthu folder
cat README.md       # file content paakuradhu

Git daily cycle

git init                      # repo start (oru vaati mattum)
git status                    # enna maaruchu, list
git diff                      # exact-ah enna lines maaruchu
git add .                     # ellaa changes-um stage pannu
git commit -m "add GET /todos"   # checkpoint save
git log --oneline             # history

Undo & branches (AI kooda work panna idhu romba mukkiyam)

git restore .                 # commit pannaadha changes ellaam discard
git restore src/app.js        # oru file mattum discard
git checkout -b try-feature   # experiment-ku puthu branch
git checkout main             # main-ku thirumba
git branch -D try-feature     # experiment fail-na branch delete
Wrong

AI kitta periya change kettu, commit pannaama, kettu pochu. Ippo edhu AI maathunadhu, edhu ungaludhu nu theriyaadhu.

Right

AI-ku task kudukkuradhukku munnaadi git commit. Pudikkalanna git restore ., 2 second-la pazhaya state.

Practice: todo-api folder create pannunga, git init, oru notes.txt ezhudhi commit pannunga. Apram file-ah maathi git diff paarunga, git restore . panni undo pannunga.

Checklist

AI-ku task kudukkuradhukku munnaadi enna pannanum?

git commit. Clean checkpoint irundha AI enna maathunaalum git diff-la paakkalaam, pudikkalanna revert pannalaam.

git status-kkum git diff-kkum enna difference?

status: endha files maaruchu nu list. diff: andha files-la endha lines maaruchu nu exact-ah kaattum.

Level 1 · Basics

Claude Code first session

Why Claude Code-la start? Terminal agent. Files padikkum, edit pannum, commands run pannum. Idhula kathukkiradhu Codex, Gemini CLI-kkum apdiye apply aagum, CLI agents ellaam ore concept.

Start & first prompt

cd ~/Desktop/Learn_Claude_Code/todo-api
claude                        # interactive session
claude -c                     # kadaisi conversation continue
claude -r                     # pazhaya session select panni resume

First prompt-ah simple-ah vachukkunga: indha folder-la enna irukku nu explain pannu. AI files-ah eppadi padikkudhu nu paarunga.

Checklist

Full repo-va dump pannaama oru file-ah mattum eppadi point pannuradhu?

@path/to/file mention. Context chinnadha irundha AI focus-ah irukkum.

AI thappaana direction-la poyittu irukku. Enna pannuveenga?

Esc press panni stop, correct direction sollunga. Mudiyura varaikkum wait panna vendaam, wasted time + messy changes.

"Naan Claude Code-la default mode-la start pannuven, trust build aana apram accept-edits. Specific files-ah @mention panni context-ah focused-ah vachukkuven."

Level 2 · Context

CLAUDE.md & nalla prompts

Why? AI-oda output quality = neenga kudukkura context quality. Ovvoru session-um AI-ku memory illama start aagum. Instructions file dhaan adhoda "onboarding document".

Context window na enna?

AI orey nerathula "nyaabagam" vachukka mudiyura text alavu. Unga messages, files, command outputs ellaam idhula fill aagum. Fill aaga aaga pazhaya vishayangal blur aagum, quality kuraiyum. Adhunaala dhaan: orey session = orey task, mudinjadhum /clear.

Nalla CLAUDE.md eppadi irukkanum

# Todo API

## Commands
- Install: npm install
- Test: npm test
- Dev: npm run dev

## Structure
- src/routes/   → Express routes
- src/services/ → business logic
- tests/        → vitest + supertest

## Rules
- Puthu dependency add pannuradhukku munnaadi kelu
- Ovvoru endpoint-kkum test kandippa
- Error format: { "error": "message" }
- console.log commit pannaadhe
Wrong

500 lines CLAUDE.md, full documentation copy-paste. AI-ku edhu mukkiyam nu theriyaadhu, context waste.

Right

Short & specific: commands, structure, rules. AI repeat-ah thappu pannuradha paathaa, adha oru line rule-ah add pannunga.

Locations: ./CLAUDE.md (project, team kooda git-la share), ~/.claude/CLAUDE.md (ungal personal, ellaa projects-kkum). /memory vachu edit pannalaam.

Prompt formula: Goal + Location + Constraints + Done

Wrong
login fix pannu
Right
Goal: email invalid-na submit disable aaganum.
Location: src/auth/LoginForm.tsx
Constraints: src/utils/validators.ts-la
  irukkura validator reuse pannu.
  Puthu library vendaam.
Done: LoginForm.test.tsx-la test,
  npm test pass aaganum.

Vague prompt → AI guess pannum → guess = hallucination, thevai illadha changes, over-engineering.

Practice: /init run panni CLAUDE.md create pannunga, mela irukkura maadhiri rules add pannunga. /clear panni "POST /todos add pannu" nu sollunga. AI unga rules-ah (test, error format) follow pannudha nu check pannunga.

Checklist

Long conversation-la AI quality yen kuraiyudhu?

Context window fill aagudhu. Pazhaya, thevai illadha info naduvula mukkiyamaana info blur aagudhu. Fix: puthu task-ku /clear, illana /compact.

CLAUDE.md-la enna podanum, enna podakoodaadhu?

Podanum: commands, structure, rules, conventions. Podakoodaadhu: secrets/API keys, full docs, code-la already theriyura vishayam.

"Ovvoru project-kkum instructions file maintain pannuven: build/test commands, conventions, rules. AI repeat-ah oru mistake pannuna, adha rule-ah add pannuven. Adhunaala team full-um consistent output kidaikkum."

Level 3 · Workflow

Plan → Small steps → Verify → Review

Why? Idhu dhaan vibe coding-ah engineering-ah maathura level. Interview-la "unga workflow enna?" nu kekkum podhu idhu dhaan answer.

Step 1: Plan mode

# Shift+Tab → plan mode
PUT /todos/:id and DELETE /todos/:id add pannanum.
Existing code-ah padichu plan kudu: endha files maarum,
enna tests venum, edge cases enna. Code ezhudhaadhe.

Plan-ah padinga. Thappu irundha appove sollunga: "validation-ah service layer-la vai, route-la vendaam". Plan ok aanadhum implement panna sollunga.

Step 2: Chinna steps + commit

Wrong
Full todo app build pannu with auth,
DB, frontend, deployment
Right
Plan-la step 1 mattum: PUT /todos/:id
+ test. npm test run pannu. Niruthu.

Ovvoru step mudinjadhum: git diff → review → npm test → git commit. Apram dhaan next step.

Step 3: Verification loop (agentic loop)

Read code→Plan→Edit→Run tests→Fail? Fix↺Pass ✓

Test command CLAUDE.md-la irundha AI thaanaave indha loop-ah oattum. Test-first bug fix dhaan best pattern:

Empty title-oda POST /todos panna 400 varanum, aana 201 varudhu.
1. Mudhalla idha reproduce pannura failing test ezhudhu
2. Test fail aagudha nu run panni confirm pannu
3. Apram fix pannu
4. npm test, ellaa tests-um pass aaganum

Step 4: Review checklist (ovvoru diff-kkum)

  • Hallucination: illadha function, library, API method use pannirukka?
  • Security: hardcoded secrets, SQL injection, input validation, auth check miss?
  • Edge cases: empty input, illadha id, null, periya data?
  • Duplication: existing util irukkum podhu puthusa ezhudhirukka?
  • Scope creep: kekkaadha files-ah maathirukka?
  • Tests: test real-ah behaviour-ah check pannudha, illa summa pass aagura maadhiri ezhudhirukka?

Puriyaadha line irundha: Line 23 enna pannudhu, yen indha approach? nu kelunga. Puriyaadha code-ah commit pannaadheenga.

Practice: PUT + DELETE endpoints-ah plan mode → step-by-step → test → review → commit cycle-la build pannunga. Apram oru bug-ah neengale purposely podunga, test-first fix pannunga.

Checklist

Yen code-ku munnaadi plan?

Thappaana design-ah plan stage-la pudikkiradhu oru message. Code ezhudhina apram pudichaa, rewrite + review + test ellaam waste.

Bug fix-ku yen failing test mudhalla?

Bug reproduce aagudha nu proof. Fix work aagudha nu proof. Future-la thirumba vandha regression-ah pudikkum.

"Periya feature-na plan mode-la plan vaangi review pannuven. Chinna steps-ah implement, ovvoru step-um tests run panni commit. Bug-na mudhalla failing test. Ovvoru diff-um security, edge cases-ku review pannuven."

Level 4 · Advanced

Automation: commands, hooks, MCP, subagents

Why? Basics-la AI-ah use pannureenga. Advanced-la AI-ah customize pannureenga: repeat aagura work-ah automate, external tools connect, parallel work. Senior level interview-la idhu kekkum.

Custom slash commands / skills

Adikkadi type pannura prompt-ah oru command-ah save pannunga.

# .claude/commands/review.md
Current git diff-ah review pannu:
- Security issues
- Missing tests
- Edge cases
Ovvoru issue-kkum file:line kudu.

Ippo /review type panna podhum. Folder-oda periya workflows-ku .claude/skills/<name>/SKILL.md (skills). Team-oda git-la share pannalaam.

Hooks: AI enna pannaalum auto-va nadakkanum

Hooks = specific event-la guaranteed-ah run aagura shell command. CLAUDE.md-la "format pannu" nu sonnaa AI maranthudalaam, hook maraakkaadhu.

// .claude/settings.json — file edit pannadhum prettier run
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{ "type": "command", "command": "npx prettier --write ." }]
    }]
  }
}

Events: PreToolUse (block pannalaam), PostToolUse, Stop, UserPromptSubmit... /hooks vachu paakkalaam.

MCP: AI-ah external tools kooda connect

Model Context Protocol: GitHub, database, browser, Figma, Slack maadhiri tools-ah AI use panna oru standard. Claude Code, Codex, Cursor, Gemini CLI ellaam support pannum. Oru MCP server ezhudhina ellaa tool-layum work aagum.

claude mcp add <name> -- <command to start server>
claude mcp list
# session-kulla: /mcp

⚠ Trust pannura MCP servers mattum install pannunga. Adhu unga data, credentials-ah access pannalaam.

Subagents: focused helpers

Subagent = thani context-oda oru helper AI. Periya search / review-ah adhu kitta kuduthaa, main conversation-oda context clean-ah irukkum.

# .claude/agents/test-writer.md
---
name: test-writer
description: Puthu code-ku vitest tests ezhudha use pannu
---
Nee test specialist. Edge cases-ku mukkiyathuvam kudu...

/agents vachu create / manage pannalaam.

Git worktrees: parallel tasks

git worktree add ../todo-auth -b feature/auth
cd ../todo-auth && claude     # idhu oru terminal
# innoru terminal-la main folder-la vera task
git worktree remove ../todo-auth   # mudinjadhum

Rendu AI sessions orey files-ah maathi conflict aagaadhu.

Headless mode: scripts & CI

claude -p "src/ folder-la TODO comments list pannu"
git diff | claude -p "indha diff-ku commit message ezhudhu"

Checklist

CLAUDE.md rule vs Hook, enna difference?

CLAUDE.md = suggestion, AI follow pannum (most of the time). Hook = guaranteed, harness run pannum, AI-oda choice illa. "Kandippa nadakkanum" na hook.

MCP yen important?

Open standard. Oru integration ezhudhina ellaa AI tools-layum work aagum. AI-ku real data (DB, GitHub issues, docs) access kidaikkum.

"Repeat aagura review-ah slash command-ah vachirukken, formatting-ku hook. GitHub-ku MCP connect panni issues-ah direct-ah padikka vaippen. Parallel features-ku git worktrees."

Level 6 · Interview prep

Kekkura questions & answers

Strategy: Theory mattum pesaadheenga. Ovvoru answer-layum "naan idha pannen, idhu nadandhuchu" nu oru real example. Level 1–5 practice dhaan andha examples.
Unga AI coding workflow-ah explain pannunga.

"Project-ku instructions file set pannuven: commands, conventions. Periya task-na plan mode-la plan vaangi review. Chinna steps-ah implement, ovvoru step tests run panni commit. AI code-ah line-by-line review pannuven, especially security, edge cases. Prototype-ku speed, production-ku correctness."

Vibe coding pathi enna nenaikkireenga?

"Prototypes, ideas validate panna super. Aana production-la code padikkaama accept panna tech debt, security bugs varum. Naan AI-assisted engineering pannuven: AI ezhudhum, naan own pannuven."

AI hallucinate pannuna eppadi handle pannuveenga?

"Tests dhaan first defense: illadha API use pannuna build/test fail aagum. Review-la unfamiliar library/method paatha docs check pannuven. Context-ah nalla kuduthaa (relevant files, rules) hallucination kuraiyum."

AI generated code-oda security-ah eppadi ensure pannuveenga?

"Review checklist: secrets, input validation, injection, auth. Secrets-ah eppovum env-la, instructions file-la 'no hardcoded secrets' rule. CI-la lint + security scan. Sensitive code-ku extra manual review."

AI tools use panna productivity real-ah increase aagudha?

"Boilerplate, tests, refactors, unfamiliar codebase explore pannuradhu, idhula romba fast. Complex design decisions-la naan dhaan lead. Review time-ah count pannaama 'fast' nu solla mudiyaadhu. Overall, nalla workflow irundha clear-ah gain."

Team-la AI tools-ah eppadi standardize pannuveenga?

"Repo-la shared instructions file (CLAUDE.md / AGENTS.md) git-la commit, shared slash commands, hooks for formatting/lint. AI code-kkum normal PR review process. Ellaarum same rules follow pannuvaanga."

Context window, MCP, agent, idhellaam enna?

Context window: AI orey nerathula paakka mudiyura text limit. MCP: AI-ah external tools (DB, GitHub) kooda connect panna open standard. Agent: plan → tool use (read/edit/run) → result paathu → repeat pannura AI loop.

AI kooda work pannumbodhu neenga panna oru mistake sollunga.

Unga sondha story ready pannunga. Example: "Mudhalla ore prompt-la periya feature kettein, 15 files maaruchu, review panna mudiyala. Ippo plan + chinna steps + per-step commit." Mistake + learning = strong answer.
