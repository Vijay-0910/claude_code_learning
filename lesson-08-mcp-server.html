Step 4 · Build

Todo MCP server: TypeScript

Official TypeScript SDK v2 (@modelcontextprotocol/server). Pazhaiya v1 package @modelcontextprotocol/sdk; tutorials-la adhu paappeenga, API konjam vera.

terminal
$ mkdir todo-mcp && cd todo-mcp
$ npm init -y
$ npm pkg set type=module
$ npm install @modelcontextprotocol/server zod tsx
$ mkdir src
src/index.ts
import { McpServer } from '@modelcontextprotocol/server';
import { StdioServerTransport } from '@modelcontextprotocol/server/stdio';
import * as z from 'zod/v4';

type Todo = { id: number; title: string; done: boolean };
const todos: Todo[] = [];

const server = new McpServer({ name: 'todo-mcp', version: '1.0.0' });

// TOOL: model decide pannum. Description = model-oda "manual"
server.registerTool(
  'add_todo',
  {
    description: 'Add a todo item. Use when the user asks to remember or plan a task.',
    inputSchema: z.object({
      title: z.string().min(1).max(200).describe('Short task title')
    })
  },
  async ({ title }) => {
    const todo = { id: todos.length + 1, title, done: false };
    todos.push(todo);
    return { content: [{ type: 'text', text: `Added #${todo.id}: ${title}` }] };
  }
);

server.registerTool(
  'complete_todo',
  {
    description: 'Mark a todo as done by its numeric id.',
    inputSchema: z.object({ id: z.number().int().positive() })
  },
  async ({ id }) => {
    const todo = todos.find(t => t.id === id);
    if (!todo) {
      // isError: true → model error-ah padichu thirumba try pannum
      return { isError: true, content: [{ type: 'text', text: `No todo with id ${id}. Call list via the todos://all resource.` }] };
    }
    todo.done = true;
    return { content: [{ type: 'text', text: `Completed #${id}` }] };
  }
);

// RESOURCE: read-only data, URI vachu
server.registerResource(
  'all-todos',
  'todos://all',
  { title: 'All todos', description: 'Every todo as JSON', mimeType: 'application/json' },
  async uri => ({
    contents: [{ uri: uri.href, mimeType: 'application/json', text: JSON.stringify(todos) }]
  })
);

// PROMPT: user invoke pannura template
server.registerPrompt(
  'plan-day',
  {
    title: 'Plan my day',
    description: 'Turn open todos into a time-blocked plan',
    argsSchema: z.object({ hours: z.string().describe('Working hours available') })
  },
  async ({ hours }) => ({
    messages: [{
      role: 'user' as const,
      content: { type: 'text' as const, text: `I have ${hours} hours. Plan these todos: ${JSON.stringify(todos)}` }
    }]
  })
);

async function main() {
  const transport = new StdioServerTransport();
  await server.connect(transport);
  console.error('todo-mcp running on stdio');   // stderr!
}

main();
APISignature
new McpServer(){ name, version }
registerTool(name, { description, inputSchema }, handler) → { content: [...], isError? }
registerResource(name, uri | new ResourceTemplate('users://{id}', { list: undefined }), metadata, read) → { contents: [{ uri, text | blob, mimeType? }] }
registerPrompt(name, { title, description, argsSchema }, handler) → { messages: [{ role, content }] }
server.connect(transport)stdio: StdioServerTransport. HTTP: SDK docs "HTTP serving" page paarunga
Zod schema-la irundhu SDK thaane JSON Schema generate pannum, handler odurathukku munnadiye arguments validate pannum. Invalid call handler-ku varaadhu.

Step 6 · Claude API

MCP connector: Messages API-la irundhu remote MCP

Unga app code-la MCP client ezhudha vendaam. Anthropic server-side-aa unga remote (URL) MCP server-ku connect pannum. Beta: mcp-client-2025-11-20.

connector.ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const response = await client.beta.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  betas: ["mcp-client-2025-11-20"],
  mcp_servers: [
    {
      type: "url",
      url: "https://todo.example.com/mcp",
      name: "todo",
      authorization_token: process.env.TODO_MCP_TOKEN
    }
  ],
  tools: [{ type: "mcp_toolset", mcp_server_name: "todo" }],   // rendum kandippa venum
  messages: [{ role: "user", content: "Add 'renew passport' to my todos" }]
});
FieldRule
mcp_servers{ type: "url", url, name, authorization_token? }. Remote URL mattum; stdio illa
mcp_toolsetOvvoru server-um sariyaa oru toolset-la reference aaganum; illana validation error
default_configE.g. { enabled: false } = allowlist mode
configsPer-tool override, tool name key
PlatformsClaude API, Claude Platform on AWS, Foundry (beta). Bedrock / Vertex-la illa
Step 7 · Security

MCP security checklist

RiskFix
Model thappaana input anuppumZod-la strict schema: .min(), .max(), .int(), enums. Handler-layum business checks
Over-powered toolsLeast privilege: run_sql(query) vendaam; get_order(id) maadhiri narrow tools. Read-only DB user
Secrets leakEnv vars (-e API_KEY=..., ${VAR} in .mcp.json). Code / git-la hardcode illa
Prompt injectionTool output (web page, ticket text, email) untrusted data. Adhula "ignore previous instructions" irukkalaam. Destructive actions-ku human approval
Untrusted third-party serversSource paathu, trusted publishers mattum. Project .mcp.json servers-ah Claude Code approve kekkum
Remote server authOAuth / bearer token; HTTPS mattum
Wrong

  z.object({ query: z.string() }) }, ...)

Model (or injected prompt) DROP TABLE pannalaam.

Right

  z.object({ id: z.number().int() }) }, ...)

Narrow, parameterized, read-only query ulla.

Step 10 · Check

Quick quiz (exam style)

1. Stdio MCP server Claude Code-la connect aagudhu, aana first call-laye fail. Code-la console.log irukku. Cause?

Stdio-la stdout = JSON-RPC channel. console.log protocol-ah corrupt pannudhu. console.error (stderr) use pannunga.

2. Product catalog (read-only) model-ku kudukkanum. Tool-aa resource-aa?

Resource. Read-only, app/user-controlled data. Tools = actions, model-controlled.

3. Messages API-la mcp_servers mattum kuduthinga, error varudhu. Yen?

tools-la matching { type: "mcp_toolset", mcp_server_name } kandippa venum, kooda beta mcp-client-2025-11-20.

4. Team-wide remote server, 50 developers, internet-la odanum. Transport?

Streamable HTTP + OAuth / token auth. Stdio local process-ku mattum. SSE deprecated.

5. Support-ticket MCP tool ticket text return pannudhu; adhula "delete all customers" nu irukku. Risk name + defence?

Prompt injection (indirect). Tool output-ah untrusted data-aa treat pannunga, tools least-privilege-aa vachunga, destructive actions-ku human approval / hooks.

6. Tool call-la id kedaikkala. Throw pannanumaa?

Illa: { isError: true, content: [...] } return pannunga, clear message-oda. Model padichu correct-aa retry pannum.

Interview line

"MCP = AI apps-kaana open standard. Naan TypeScript SDK-la server build pannen: actions-ku tools, read-only data-ku resources, templates-ku prompts. Zod vachu input validate, logs stderr-ku, secrets env-la, narrow least-privilege tools. Local-ku stdio, remote-ku Streamable HTTP; API-la irundhu MCP connector vachu call."
