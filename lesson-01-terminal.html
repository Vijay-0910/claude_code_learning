Step 0 · Why

Yen terminal mudhalla kathukkanum?

Claude Code, Codex, Gemini CLI: moonume terminal-la dhaan odum. AI "file create panniten" nu sonna, adhu unmaiyaa nu neenga ls, cat vachu check pannanum.

"Naan enga irukken? Inga enna files irukku?" nu theriyalana, AI sonnadhai kanmoodithanamaa nambura nelamai varum. Adhu dhaan vibe coding. Check panradhu dhaan engineering.

Golden rule: Check → Act → Verify. Mudhalla enga irukkom nu paaru, apram command, apram result-ah verify pannu.
Step 1 · Concept

Path na enna?

Commands-ku munnadi idhu theriyanum. Path = oru file/folder-oda address.

SymbolMeaningExample
/Root: full system-oda top folder/home
~Unga home folder (/home/vijayakumar)~/Desktop
.Current folder (ippo irukkura idam)./notes.txt
..Parent folder (oru level mela)../other
Relative path
cd todo-api

Ippo irukkura folder-la irundhu. Location maarina, idhu fail aagum.

Absolute path
cd ~/Desktop/Learn_Claude_Code/todo-api

Enga irundhaalum work aagum. / or ~-la start aagum.

Step 3 · Command

ls: inga enna irukku?

list. Options-ah combine pannalaam: -l -a -h = -lah.

CommandEnna pannum
lsCurrent folder-la irukkura files/folders names
ls -lLong format: permissions, owner, size, date
ls -aAll: hidden files-um (.-la start aagura .git, .env)
ls -laLong + hidden. Most used combo
ls -lhHuman readable size: 50K, 2.1M (bytes illa)
ls -ltTime sort: recent-ah maathuna file mela. AI edit-ku apram super useful
ls -ltrTime sort, reverse: pazhaiyadhu mela, puthusu keezha
ls -lSSize sort: periya file mela
ls -RRecursive: ella sub-folders-kulla-um list
ls -1Ovvoru line-la oru file
ls -d */Folders mattum
ls todo-apiVera folder-ah, ulla pogaama paakuradhu
ls *.mdPattern: .md-la mudiyura files mattum (* = wildcard)
 
$ ls -lah
total 68K
drwxrwxr-x 2 vijayakumar vijayakumar 4.0K Oct 13 15:49 .
-rw-rw-r-- 1 vijayakumar vijayakumar 1.2K Oct 13 13:05 CLAUDE.md
-rw-rw-r-- 1 vijayakumar vijayakumar 2.6K Oct 13 13:05 LEARNING_PLAN.md
# d = directory (folder),  - = file,  rw- = read/write permission

Step 5 · Command

mkdir: puthu folder

make directory.

CommandEnna pannum
mkdir todo-apiOru folder create
mkdir src tests docsOrey nerathula pala folders
mkdir -p src/routes/v1Parents: nadula irukkura folders illana adhaiyum create pannum. Already irundha error varaadhu
mkdir -v logsVerbose: "created directory 'logs'" nu sollum
mkdir -pv a/b/cRendum combine
Wrong
mkdir src/routes/v1
mkdir: cannot create directory: No such file or directory

src illa, adhanaala fail.

Right
mkdir -p src/routes/v1
ls -R src

-p full chain-ah create pannum, apram verify.

Step 6 · Command

cat: file content paakuradhu

concatenate. Chinna files-ku cat, periya files-ku less/head/tail.

CommandEnna pannum
cat CLAUDE.mdFull content print
cat -n CLAUDE.mdLine numbers-oda. AI "line 12-la bug" nu sonna check panna
cat a.txt b.txtRendu file-um onna serthu print
head fileMudhal 10 lines mattum
head -n 20 fileMudhal 20 lines
tail fileKadaisi 10 lines
tail -f app.logFollow: puthu lines vara vara live-ah kaattum (server logs). Ctrl+C to stop
less filePage by page scroll. q to quit, / to search
Danger
cat > CLAUDE.md

> file-ah overwrite pannidum. Ulla irundhadhu ellam pochu.

Safe
cat CLAUDE.md
less ai-coding-path.html

Read mattum. Edhuvum maaradhu.

Step 9 · Check

Quick quiz

Mudhalla neengalae yosichu answer sollunga, apram click panni paarunga.

1. .env file irukkaa nu ls vachu eppadi paakuradhu?

ls -a (or ls -la). .-la start aagura files hidden. -a illama theriyaadhu.

2. mkdir a/b/c error kudukudhu. Yen? Fix enna?

a, a/b innum illa. mkdir -p a/b/c nadula irukkura folders-aiyum create pannum.

3. AI 10 files edit pannuchu. Edha files maaruchu nu terminal-la quick-ah eppadi paakuradhu?

ls -lt: recent-ah maathuna files mela varum. (Next lesson-la git status / git diff idhai innum better-ah pannum.)

4. cd .. vs cd - difference?

cd .. = parent folder (oru level mela). cd - = mundhi irundha folder (enga irundhaalum).
